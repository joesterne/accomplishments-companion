Three-stop reference route

This is a source walkthrough and reference route, not a record of learner-led editor navigation. Paths below are relative to the repository root.

1 · Conversation rules

.agents/skills/accomplishments-companion/SKILL.md

Search for Correct through conversation. Codex follows instructions to clarify ambiguous corrections, keep stable IDs, and preserve unrelated content. This file also controls when to offer a summary; the Python helper does not decide when the person is ready.

2 · Content and safe revisions

.agents/skills/accomplishments-companion/scripts/render_summary.py

Search for validate, html_document, and render. The helper checks the input shape, escapes text for HTML, and writes a complete pair into a new revision directory. It cannot judge whether an accomplishment is true; the conversation must preserve the person's meaning.

3 · Appearance and downloads

.agents/skills/accomplishments-companion/assets/summary.html

Search for .intro, download-html, and download-text. The template supplies styles, headings, lists, and download controls. Both downloads use the content from the same rendering run.

What can travel between agents?

The conversation instructions, Python helper, input contract, and HTML template are reusable files. The helper needs Python 3.9+ and only its standard library.

How an agent finds the skill, grants permission to execute its helper, and displays generated files depends on the host. The .agents/skills/ discovery path and agents/openai.yaml metadata belong to this Codex setup. Claude and Gemini compatibility have not been tested.

A practice to reuse

Separate conversational decisions from repeatable formatting, then test each where it happens. The three-accomplishment offer was checked through actual agent conversations. Revision preservation was checked by test_revision_preserves_unrelated_content_and_previous_files in tests/test_render_summary.py, and downloads were compared after real browser use.

On another project, write one observable outcome first, identify which component is responsible, and choose a check that exercises that component. A renderer test cannot prove that an agent asks the right question.

Run it again

Open the repository in Codex and ask to use $accomplishments-companion. To generate the fictional demo directly, run this from the repository root:

python3 .agents/skills/accomplishments-companion/scripts/render_summary.py --input examples/demo-summary.json --output-dir outputs/demo

Open the exact HTML and text paths printed after success. Generated files are kept under ignored outputs/. The in-app browser's local-file restriction is described in the README; an ordinary browser can be used to open the local HTML.

Optional small practice: change the introductory sentence in the template, regenerate the fictional demo, and compare the result. No such edit was made during this walkthrough.

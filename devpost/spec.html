Accomplishments Companion

A small skill.
A useful take-away.

Codex holds the conversation. A small helper turns its agreed content into a consistent browser document and a reusable text copy.

The approach you chose

Start in Codex. Explore real accomplishments. Review and correct through chat. Keep a browser-readable summary and plain text.

How the pieces connect

Learner-selected

Experience

Codex first, a clean and modern summary, browser and text outputs, and Section 508 as the accessibility target.

The three-accomplishment offer, early summaries on request, and chat-based corrections carry forward unchanged.

Approved implementation

Small local helper

Use Python’s built-in tools to validate content and generate both outputs from one source. A fixed HTML template keeps the layout consistent.

Python is already available here. No additional runtime packages are planned.

Follow one action

Each reveal connects the user's experience to the proposed files and checks.

1 · Invoke the skill and find accomplishments

The skill guides reassurance, targeted questions, the three-example offer, and early-summary requests. Codex handles the actual conversation.

.agents/skills/accomplishments-companion/SKILL.md

Check: actual skill discovery and a real conversation with two examples followed by a third.

2 · Turn agreed content into a document

Codex supplies a structured list with supporting user excerpts, encouragement, and suggested next steps. The helper validates it and renders the content safely.

scripts/render_summary.py + references/summary-format.md

Check: faithful examples, invalid input rejection, Unicode, and literal markup handled as text.

3 · View and download both formats

The standalone browser document has clear headings, lists, and download controls. The text copy comes from exactly the same content.

assets/summary.html → generated HTML and text under outputs/

Check: real downloads, matching content, keyboard access, contrast, reading order, and text enlargement.

4 · Correct one accomplishment

A conversational edit updates the matching entry. Ambiguous edits lead to clarification. A completed new revision gets fresh links; older saved copies stay unchanged.

Check: the intended correction appears, unrelated accomplishments stay intact, and a failure preserves the previous successful revision.

Your learning question

What can travel between agents?

The workflow instructions, template, and helper are reusable files. How an agent discovers the skill, runs its helper, and presents the files depends on the host.

During the build, we’ll follow one real conversation-to-document action and identify the Codex-specific pieces. Other-agent compatibility remains untested.

How we’ll verify it

  • Real Codex conversations for the offer, early requests, and corrections.
  • Automated helper tests for content, output consistency, and failures.
  • Browser and applicable accessibility checks with results recorded.
  • Your hands-on trial before the build is complete.

What still needs evidence

Skill discovery, file downloads, conversational fidelity, and accessibility all need actual checks.

A page that looks clean is not evidence of full Section 508 conformance. The plan distinguishes our output from the host interface and records untested areas.

Try locally, record the proof

Open this project in Codex and invoke the companion skill. Its generated HTML opens in a browser; the text file opens in a text viewer. No deployment is selected.

The demo will show three fictional accomplishments, the offer, the summary, one correction, and the revised download. A demo video and public repository remain the shipping deliverables.
